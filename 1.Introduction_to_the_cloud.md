##### 1] What is cloud ?

```
In starting stages they are used to buy the new server to deploy their applications (for eg : IBM, HP server providers)

Buy and bring those 15-20 servers and build a data centre
A data centre is a place where all the servers are stored and all the configurations done for the servers.

Very costly and comes with huge configurations like 1 server with 100gb ram with 100 cpu and you are deploying one applications that requires 1 ram and 1 cpu all the remaining thing will get wasted.

To solve this problem there is a concept came called Virtualization 

In this concept where you will solve the problem of wasting resources on server.
By using virtualization you can create a virtual server on the same server to deploy more applications ( virtual server is nothing but on top of the actual server we are creating a virtual layer and in each virtual server we can deploy one application Okay)
Instead of buying 15 servers for 15 application we can buy one server with the required configuration so that we can deploy 15 applications Okay..

If my organization in the us and india if i request 5 virtual machines to deploy my application as a devops engineer we can create 5 virtual machines and their IP address so that they can access that virtual machine and we dont know where exactly the servers are located.

System administrators managing this entire things Okay.
```
